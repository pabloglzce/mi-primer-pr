# mi-primer-pr
Repositorio de practica para aprender a hacer mi primer Pull Request
## Objetivo

Este repositorio existe para practicar el flujo de trabajo de Git y GitHub: crear una rama, hacer un cambio pequeño y abrir un Pull Request.

## Como contribuir

1. Crea una rama nueva a partir de `main`.
2. Haz tu cambio.
3. Abre un Pull Request describiendo que cambiaste y por que.
